# Md Alvi Hasan Emon — GitHub Pages Portfolio

Responsive dark-premium portfolio made with plain HTML, CSS, and JavaScript. No build step or package installation required.

## Publish for free
1. Sign in to GitHub as `mdalvihasanemon`.
2. Create a **Public** repository named exactly `mdalvihasanemon.github.io`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then Save.
6. Wait a few minutes, then visit `https://mdalvihasanemon.github.io`.

## Add your photo later
In `index.html`, find:

```html
<img id="profileImage" src="PASTE-YOUR-IMAGE-URL-HERE" alt="Portrait of Md Alvi Hasan Emon">
```

Replace only `PASTE-YOUR-IMAGE-URL-HERE` with a direct, publicly accessible image URL. Or upload your photo into an `assets` folder in this repository and use `src="assets/profile.png"` (make sure the filename matches exactly). A local Windows path such as `C:\\Users\\...\\photo.png` will not work online.
